# Oydin

**Oydin** is a visual workspace for capturing, organizing, and developing ideas.

The project explores a simple concept: giving thoughts a flexible space where they can be written, positioned, connected, and explored visually.

## Features

- Visual idea workspace — **Makon**
- Create, edit, move, and organize thoughts
- Connect related ideas visually
- Zoom and navigate the workspace
- Light and dark themes
- Multiple workspace backgrounds
- Responsive desktop and mobile interface
- Local data persistence

## Tech Stack

- HTML
- CSS
- JavaScript
- SVG
- Browser Local Storage
- GitHub
- Cloudflare Pages

The current version does not use an AI API or external backend.

## Run locally

```bash
git clone https://github.com/alisher-ds/oydin-uz.git
cd oydin-uz
python -m http.server 8000
```

Open `http://localhost:8000` in a browser.
