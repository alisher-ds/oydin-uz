# Oydin

> A visual space for capturing, connecting, and developing ideas.

Oydin is an experimental personal thinking workspace built to explore a simple question: **what if scattered thoughts could become easier to see, connect, and develop?**

The project is intentionally lightweight and focused on the experience of working with ideas rather than becoming another all-purpose notes or project-management application.

## ✨ What is Oydin?

Oydin gives users a visual **Makon** (space) where thoughts can be placed, moved, connected, and developed.

Instead of forcing ideas into rigid pages, folders, or databases, Oydin experiments with a more spatial approach:

**capture → arrange → connect → develop**

The current version is a frontend-focused prototype and does not require an AI API.

## 🧩 Core Features

- 🧠 **Makon** — a visual workspace for thoughts and ideas
- ✍️ **Thought capture** — quickly add ideas to a space
- 🔗 **Connections** — visually connect related thoughts
- 🖱️ **Free positioning** — move thoughts around the workspace
- 🔍 **Zoom & navigation** — explore larger idea spaces
- 📱 **Responsive interface** — designed for desktop and mobile interaction
- 🌙 **Light / dark modes** — alternative visual environments
- 🎨 **Multiple space backgrounds** — personalize the visual atmosphere
- 💾 **Local persistence** — current prototype can preserve workspace data locally
- 🧭 **Separate pages** — landing/about experience and the working Makon are separated

## 🎯 Project Philosophy

Oydin is not intended to compete with general-purpose tools by simply adding more features.

The experiment is centered around a different interaction model: **ideas should feel like things you can explore and develop, not just rows in a list.**

The project is still evolving, and its long-term product direction is intentionally open.

## 🛠️ Technology

The current project is built as a lightweight web application using browser-native technologies and frontend tooling.

- HTML
- CSS
- JavaScript
- SVG-based visual connections
- Browser storage for prototype persistence
- GitHub for source control
- Cloudflare for deployment/hosting

No AI API is required for the current version.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/alisher-ds/oydin-uz.git
cd oydin-uz
```

Then open the project's main HTML entry point in a browser, or serve the folder with any simple local web server.

For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🧪 Why this project exists

Oydin was built as a real-world learning project while exploring frontend development, product design, interaction design, Git/GitHub workflows, deployment, responsive interfaces, and visual UX.

The project is intentionally public so that the development process and experiments can be explored by other developers and learners.
